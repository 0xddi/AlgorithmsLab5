# GraphLab

Учебная интерактивная лаборатория графовых алгоритмов на **C# / Avalonia UI 12 / .NET 9**.
Одно окно — четыре задания, каждое с визуальным редактором графа, пошаговой анимацией,
журналом операций и сохранением/загрузкой.

## Вкладки

1. **Обход графа** — полный редактор взвешенного графа, BFS/DFS, очередь/стек, дерево обхода,
   матрица смежности и CSV.
2. **Максимальный поток** — транспортная сеть, Эдмондс–Карп, остаточные дуги, узкое место,
   минимальный разрез.
3. **Остовное дерево** — Краскал и Прим, режим минимального/максимального дерева, таблица рёбер,
   сохранение MST.
4. **Кратчайший путь** — Дейкстра между выбранными пользователем вершинами, таблица расстояний,
   дерево предков и анимированный маршрут.

## Управление демонстрацией

- **⏮ Сначала** — вернуться к первому шагу.
- **◀ Шаг назад / ▶ Шаг вперёд** — пошаговый просмотр (автоматически ставит на паузу).
- **▶ Пуск / ⏸ Пауза** — автоматическая анимация.
- слайдер — произвольная перемотка;
- скорость — `0.5× … 2×`;
- `Space` — пуск/пауза активной вкладки.

## Редактор

- режимы: **Выбор / + Вершина / + Ребро / Удалить**;
- вершины перетаскиваются мышью, метки и веса меняются в инспекторе;
- раскладки: по кругу, сеткой, пружинная (с плавной анимацией);
- **Del** — удалить выбранное, **Esc** — отменить создание ребра;
- любое изменение графа сбрасывает построенный сценарий.
